# 今天吃什么

一个手机优先的「吃什么」决策助手 + 家里食材反推菜谱的小工具。

## 两个区块

- **不知道吃什么**：问几个问题（自己做还是外卖 / 荤素 / 辣度 / 想吃什么形态），再问一轮软偏好（下饭、减脂、带汤、一人食……），从菜谱库里挑 12 道。
- **家里有食材**：输入你有的食材，反推能做的菜。

点进任意一道菜能看到做法步骤、小窍门，以及跳转到下厨房 / B 站搜教程的按钮。

## 技术形态

纯静态 PWA：没有后端，没有数据库，全部计算在浏览器里完成。菜谱是打包在 `data/` 里的 JSON。

## 本地跑

```
npm start          # http://localhost:8080
```

手机同 WiFi 访问 http://<你电脑的局域网IP>:8080。

## 常用命令

| 命令 | 作用 |
|---|---|
| `npm start` | 启动本地预览服务器 |
| `npm run validate` | 校验菜谱数据（字段、枚举、重名、覆盖度） |
| `npm run build` | 生成 `dist/`，用于部署 |
| `npm run icons` | 重新生成应用图标 |

## 加菜谱

在 `data/dishes/` 下新增 `batch-NN.json`，并把文件名写进 `data/index.json` 的 `files` 数组，然后跑 `npm run validate`。
